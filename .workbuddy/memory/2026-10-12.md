# 2026-10-12 工作日志

## 排查并修复后端 MySQL 连接报错（项目：智能学生课表管理系统）

- **现象**：启动后端报 `sqlalchemy.exc.OperationalError (pymysql.err.OperationalError) (1049, "Unknown database 'db'")`。
- **报错链路**：`app/main.py:6 Base.metadata.create_all(bind=engine)` → `app/database.py:8 create_engine` → `app/config.py:8` → `backend/.env:1`。
- **根本原因**：`.env` 里 `DATABASE_URL=mysql+pymysql://root:<pwd>@127.0.0.1:3306/DB` 指向的 `DB` 库在 MySQL 中不存在。用户误把 Navicat 里名为「DB」的**连接**当成了数据库；Navicat 历史日志 `SERVER=DB` 实为连接名，日志中从无 `CREATE DATABASE`。
- **环境事实**：本机有两个 MySQL 实例 —— 运行中的 `/usr/local/mysql/data`（App 实际连接，库：information_schema/mysql/performance_schema/sky_take_out/sys）与未启动的 Homebrew `/opt/homebrew/var/mysql`（tlias/demo1/sky_take_out/...）。两者均无 `DB`。
- **修复**：在 127.0.0.1:3306 执行 `CREATE DATABASE \`DB\` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;`（用户授权后执行）。`.env` 未改动。
- **验证**：`python -c "from app.main import app"` 成功；`users` 表已自动建出（id/username/password/name/role/email/phone/avatar/status/create_time/update_time）。
- **遗留提示（非阻塞）**：`app/_init_.py`、`app/models/_init_.py` 用的是单下划线，应为 `__init__.py`（当前靠命名空间包能跑，但非规范）。

## 修复前端 layout 退出登录不跳转（frontend/）

- **现象**：layout 主页面「退出登录」点击无反应，不跳登录页。
- **根本原因**：`src/layouts/layout.vue` 的 `<script setup>` 中 `logout()` 调用了 `router.push('/login')`，但**未导入 router** → 运行时抛 `ReferenceError: router is not defined`，函数中断。
- **对照**：`src/views/login.vue:48` 有 `import router from '@/router'`，故其跳转正常。
- **修复**：在 `src/layouts/layout.vue` `<script setup>` 新增 `import router from '@/router'`（与 login.vue 写法一致）。
- **验证**：`vite build` 通过（✓ built）。
- **技术栈备忘**：Vue 3.5 + Vue Router 5 + Element Plus + Vite，别名 `@` → `src`；路由 `/login`、`/register` 为顶层，`/manager/*` 为 layout 子路由；无 auto-import 插件，`router` 需显式导入（图标已在 main.js 全局注册）；待办：logout 目前未清 token/本地存储。
